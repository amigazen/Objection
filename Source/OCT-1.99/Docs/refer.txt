   Below are listed the methods in the OCT system.  There abstract
   functionallity and return types are detailed.  Each class is
   free to interpret them within some leway; after all this is an
   object oriented system with data-hiding! 


        The name in square brackets ([,]) after the method protype
   is the category where the method is first defined.  Generally
   speaking, any method in this category of classes or inheriting
   from a class in this category can respond sucessfully to this
   message.  



   1.1. Factory Methods         1.1. Factory Methods
   These methods are known by factory objects.  


   initialize [Foundation]      Perform any presetting for this   initialize [Foundation]
        class.  Returing nil will cause the application to abort.
        Called before user's application begins to run.  Classes
        with complex instance variable declarations that can't be
        encoded during translation may change their text encoding.  

        A handler for cleanup may be installed by calling
        _oc_atExit().  The single parameter is a function that will
        be called in LIFO (stack) order when the application exits.  


   new [Foundation]      Allocate and initialize a new instance of   new [Foundation]
        the receiver class.  In contrast to [Cox86], in a factory
        method, it's illegal to assign the result to the variable
        `self', as that refers to the class object, and not the
        instance object! 


       + new
       {
          id newObj;

          /*  Never assign to "self" in a factory!  */
          newObj = [super new];
          newObj->capacity = 0;
          return( newObj );
       }

   1.2. Instance Methods         1.2. Instance Methods
   These methods are known by instance objects.  


   add:item [Array and Collection]    Store 'item' at the next   add:item [Array and Collection]
        available slot.  If there is a notion of a cursor in self,
        then 'item' will be after the cursored slot.  Array's
        generally store in the first unused (nil) slot.  


   at:(int)index put:(id)anObject [Foundation]     Store an object   at:(int)index put:(id)anObject [Foundation]
        into the indexing storage receiver object.  


   (int) count [Array and Collection]   Return the count of usable   (int) count [Array and Collection]
        objects contained within the object.  For Array types, 'nil'
        pointers are not counted.  (Was named 'size'.) 


   error:(STR)fmtSTR vaDcl:stuff [Foundation]     Display an error   error:(STR)fmtSTR vaDcl:stuff [Foundation]

   first [Sequence]      Sets the objects cursor to be the first   first [Sequence]

   free [Foundation]      Releases memory used by object and returns   free [Foundation]

   freeContents [Foundation]      Walks through internal contents   freeContents [Foundation]
