     Comments which precede method or  function  definitions

     Makedoc has a rudimentary macro  substitution  capabil-
ity.   Macro expansion takes place when ever the dollar sign
symbol ('$$$$') followed  by  a  single  digit  is  encountered
within  a  comment.  For method and function definitions, $$$$0000
represents the actual method or function name.  In the  case
of  method  names,  arguments  are  stripped.  Arguments are
represented as $$$$1111 through $$$$9999.  Only the first nine arguments
can  be displayed in this manner.  In the case of the intro-
ductory comments, $$$$0000 will expand to the class  name.   A  $$$$_n
token  will be silently stripped if argument number _n is not
present in the method or function definition.

     To get a dollar sign to appear in the output,  use  two
dollar signs in a row, eg: $$$$$$$$.

     _M_a_k_e_d_o_c automatically escapes any LATEX special charac-
ter  found  in  macro  arguments.   It  is up to the user to
escape these characters everywhere else.
